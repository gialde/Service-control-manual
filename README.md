# Service-control-manual

## Назначение

Сервис управления инструкциями — приложение для хранения, публикации и выдачи
доступа к производственным и техническим инструкциям. Сервис решает задачу
централизованного ведения базы знаний: вместо разрозненных файлов на дисках
пользователи получают единый каталог с понятным статусом каждой инструкции,
оценкой времени чтения и разграничением прав доступа.

## Целевая аудитория

- Технические писатели и методологи — создают и редактируют инструкции.
- Администраторы базы знаний — управляют публикацией и архивацией.
- Сотрудники предприятия — ищут и читают инструкции в рамках своей роли.
- Руководители подразделений — контролируют актуальность документов.

## Предметная область

Предметная область — управление корпоративными инструкциями и регламентами.
Ключевые процессы: создание черновика, проверка, публикация, архивация,
предоставление доступа в зависимости от роли пользователя и признака
публичности документа.

## Основные сущности

- Инструкция — документ с заголовком, текстом, статусом и датой.
- Пользователь — сотрудник, работающий с инструкциями.
- Роль — набор прав (admin, editor, reader).
- Категория — тематический раздел, к которому относится инструкция.

## Основные функции

- `get_instruction_status` — определение статуса инструкции (черновик,
  опубликована, в архиве).
- `estimate_reading_time` — оценка времени чтения инструкции по количеству слов.
- `check_user_access` — проверка права доступа пользователя к инструкции.

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
